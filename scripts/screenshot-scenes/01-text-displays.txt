# Text-display holograms: styled, shadowed, panelled world text.
#
# `text_display` is the entity family whose glyph pass this client rewrote —
# the shadow is a polygon offset rather than vanilla's geometry, and a
# `text_display` is legible from *behind*, which is exactly the premise the
# ported one-sided constant violated. Two of the panels are turned away from
# the camera's axis for that reason.
#
# The stage sits at y=63 rather than on the flat world's own surface: the
# superflat oracle's ground is y=-61, and this client applies vanilla's
# non-flat void fog (a 32-block fade above the world bottom) everywhere, so a
# camera down there sees a near-black sky. Real vanilla uses a 1-block snap in
# a flat world; ours does not know the world is flat. Building up here shows
# the renderer rather than that gap.

@size 2560 1440
@camera 0.0 66.5 4.6
@look 0.0 66.4 15.0
@fov 65
@wait 2500
