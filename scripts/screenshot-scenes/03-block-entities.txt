# Block entities: the block types whose 26.2 model file is *empty*, so every
# one of them is a hole in the terrain mesh until a render source supplies it.
#
# Banners (layered loom patterns composited into one flag mesh, with sway),
# decorated pots (four independent sherd faces), chests and shulker boxes,
# skulls and heads, an inactive conduit shell, a lit campfire cooking real
# items, a lectern holding a book, a bell, an enchanting table (four animated
# book values, none of them on the wire), and a beacon firing its beam.
#
# Two placement traps, each of which produced a false defect report:
#
#   * `minecraft:conduit`'s default block state is `waterlogged=true`, so a
#     bare `setblock` puts a real water source on the stage and the server
#     floods it out to a radius-6 diamond. That is vanilla behaviour, not a
#     renderer bug; place it `waterlogged=false`. With no prismarine frame
#     around it the conduit is *inactive*, which is the small spinning shell
#     drawn from `entity/conduit/base` — no cage, no wind, no eye.
#   * a skull's `rotation` segment 0 faces **north** (`-Z`), so a camera on
#     the `-Z` side sees the face at `rotation=0` and the back of the head at
#     `rotation=8`. The back of a skeleton skull or a zombie head is a flat
#     untextured-looking field of one colour, which reads exactly like a
#     missing texture. Banners here use `rotation=8` for the opposite reason:
#     `BannerRenderer` applies no `scale(-1, -1, 1)` flip, so their segment 0
#     points the other way.
#   * a double chest's `type=left`/`type=right` is only half the placement —
#     which neighbour a half pairs with **depends on its `facing`**.
#     `ChestBlock.getConnectedDirection` gives `LEFT` the block at
#     `facing.getClockWise()` and `RIGHT` the one at `getCounterClockWise()`,
#     so for `facing=north` a `left` half pairs **east** and for `facing=south`
#     it pairs **west**. Get the pair the wrong way round and both halves are
#     orphans, each drawing the open seam face it exists to hide against its
#     partner — a chest-shaped hole on each side, which reads as a broken
#     renderer. The pair below is `left` west of `right` and `facing=north`,
#     which is consistent.
#
# Everything with a front — the chests, the barrel — faces **north**, so the
# camera sees its face rather than its back. The same trap as the skulls, one
# block type up: a chest photographed from behind has no latch and looks like a
# crate.
