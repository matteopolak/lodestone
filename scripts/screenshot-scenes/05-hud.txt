# The HUD: tab list, scoreboard sidebar, hotbar with 3-D block items, hearts,
# hunger, XP bar and the first-person hand — over a live world.
#
# `@hud` composites the HUD pass over the world frame the way `app/redraw.rs`
# does, and `@hand` lets the first-person item pass draw (every other scene
# suppresses it). The player is put in **survival** first: vanilla's
# `canHurtPlayer()` hides the hearts, the hunger row, the bubbles and the XP
# bar together in creative, and the harness reads that gate off the live
# session rather than forcing it, so a creative capture would honestly show
# an empty HUD.
#
# The tab list's other rows are the harness's own companion clients. A vanilla
# server never sends a tab-list header or footer — that packet has no command
# behind it — so there is none here.

@size 2560 1440
@camera 0.0 65.6 6.4
@look 0.0 65.1 15.5
@fov 70
@wait 2500
@hud
@hand
