# Entities: posed armour stands, armour trims, dyed leather, variant mobs.
#
# An armour stand's pose is six independent rotations decoded off entity
# metadata, and every one of them is a separate wire field — a stand that
# ignores them stands to attention, which looks fine until there is another
# one beside it that does not. Trims are an item *component* reaching an
# entity model's overlay layer; the dyed leather is `minecraft:dyed_color`
# through the same path.
#
# `difficulty easy`, because peaceful removes hostile mobs the tick they
# spawn — an empty frame that reads as a broken spawn. `NoAI` keeps them
# still; it also halts gravity, so every one of them is placed exactly on the
# floor rather than a fraction above it.
