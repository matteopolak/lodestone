# Authoritative synched-entity-data INDEX map for protocol 776 (Minecraft 26.2).
#
# Produced by booting the real 26.2 server headlessly
# (SharedConstants.tryDetectVersion(); Bootstrap.bootStrap();) and reading every
# EntityDataAccessor off the game's own classes -- see
# oracle-java/EntityDataIndexOracle.java for the program and
# tests/entity_data_indices.rs for the assertions and the refresh recipe.
#
# Every IDX_* constant in src/packets/metadata.rs is a HAND COUNT over
# SynchedEntityData.defineId's per-hierarchy declaration-order counter, i.e. a
# number derived by counting fields across two or three source files. This dump
# is the external anchor for those counts. It has already caught two of them
# being wrong: Sheep's wool byte and Horse's variant int were both off by one,
# because AgeableMob.AGE_LOCKED (index 17) was not counted.
#
# Columns, space-separated:
#   index           the id SynchedEntityData.defineId assigned
#   owner.FIELD     the class DECLARING the accessor, and the field name
#   serializerId    wire serializer id (EntityDataSerializers.getSerializedId)
#   serializerName  the EntityDataSerializers constant, for human review only
#
# Sorted by (index, owner, field), so index COLLISIONS are adjacent lines. That
# ordering is the point: a collision is invisible in a per-class listing and is
# the load-bearing hazard in this decoder. Two live examples, both BYTE, both
# with bit-identical low bits:
#
#   8  LivingEntity.DATA_LIVING_ENTITY_FLAGS  vs  AbstractArrow.ID_FLAGS
#      0x01 = "using item"                        0x01 = "critical"
#   15 Mob.DATA_MOB_FLAGS_ID                  vs  ArmorStand.DATA_CLIENT_FLAGS
#      0x04 = "aggressive"                        0x04 = "show arms"
#
# The class set is every registered entity type's implementation class plus its
# whole superclass chain, so it is exactly what can appear on the wire, and
# nothing is enumerated by hand.
