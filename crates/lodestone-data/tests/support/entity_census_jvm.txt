# the program and tests/entity_census.rs for the generator, the reduction to a
# boolean, and the refresh recipe.
#
# Columns, space-separated:
#   id                network entity-type registry id (dense 0..158)
#   name              canonical minecraft:* identifier
#   impl              implementation class, from the generic signature of the
#                     EntityTypes constant that registered the type
#   living            LivingEntity.class.isAssignableFrom(impl)
#   mob               Mob.class.isAssignableFrom(impl) -- strictly narrower than
#                     living (a player and an armour stand are living, not mobs),
#                     and the class that declares the isAggressive() flags byte
#   pushEntitiesDecl  class in impl's hierarchy declaring pushEntities(), or -
#   doPushDecl        class in impl's hierarchy declaring doPush(Entity), or -
#   widthBits         raw f32 bits (hex) of EntityType.getWidth()
#   heightBits        raw f32 bits (hex) of EntityType.getHeight()
#
# The width/height columns duplicate tests/support/entity_dimensions_jvm.txt on
# purpose: they were dumped by a separate program on a separate run, and
# tests/entity_census.rs asserts the two agree bit-for-bit, so each anchors the
# other. Base dimensions only -- no SCALE, no STEP_HEIGHT (as there).
#
# Nothing in this file is a decision. Every column is mechanically derived, so
# the modelling step ("which of these can shove the local player") is visible in
# Rust beside its vanilla citations rather than baked in here.
